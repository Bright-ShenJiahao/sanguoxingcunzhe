# 武器 / 技能总表（2026-10-31 整理）

> **第零节是提案的完整武器表**（现有 + 补齐缺的类别），每把都写清楚「打哪里、怎么飞」。后面几节是现状和参考资料。

## 零、提案：完整武器表（第二版，按 2026-10-31 反馈修改）

### 瞄准方式（每把只用一种）
| 叫法 | 意思 | 要不要操心方向 |
|---|---|---|
| **自动索敌** | 自动打离你最近的敌人 | 不用 |
| **索敌群** | 自动打怪最密的地方 | 不用 |
| **随机** | 画面里随机挑敌人 / 位置 | 不用 |
| **移动方向** | 朝你走的方向（8 方向） | 要 |
| **左右朝向** | 只打脸朝的那一侧 | 要 |
| **围绕自身 / 脚下** | 以你为中心，或留在你脚下、身后 | 不用 |

原则：不用操心方向的伤害偏低，要操心方向的伤害偏高。所有武器最高 **8 级**。

### 反馈改动
- 掌机：移动方向 → **自动索敌**（原来杀敌效率太低）。
- 火球术：移动方向 → **索敌群**（原来太难）。
- 冰霜新星：自身冰圈 → **随机发射冰锥**，小范围减速。
- 光之枪：→ 随机方向。
- 删掉：砍刀、飞刀、水晶牢笼。
- 改名：链锤 → 长鞭；符文地雷 → 地雷；结界线 → 结界术（留在身后）；水晶牢笼 → **六芒法阵**（脚下，延迟封印加伤害）。
- 新增：从《暂时停止呼吸》借 21 个，改成西方奇幻名（★借）。
