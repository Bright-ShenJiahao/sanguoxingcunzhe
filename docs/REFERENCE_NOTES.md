# 参考笔记（他游截图的文字记录，仅供以后设计时学习，暂不实现）

## A. 结算界面「战斗数据」
- 顶部：地图名 – 难度 – 奖励（例：疯狂森林 – 普通 – 金币 x 1）
- 左侧统计：存活时间 04:36 / 获得金币 192 / 达到等级 10 / 击败敌人 704
- 武器表（列：武器、等级、伤害、时间、每秒伤害）
  - 神鞭 1级 1.5k 4:36 5.5
  - 斧头 2级 3.3k 3:59 13.8（最高项用黄色高亮）
  - 圣徒水 3级 3.1k 3:47 13.7
  - 国王圣经 2级 1.1k 3:03 5.8
  - 强能魔杖 1级 1.3k 2:34 8.4
- 右侧：角色名 + 头像；下方一排本局拿到的武器图标及等级、再下一排被动/道具图标及数量
- 底部：「新成就！」条（如：升到10级 → 解锁：王冠），旁边红圈「N 解锁！」
- 按钮：「隐藏成就」（绿）、「完成」（蓝）

## B. 局外成长「强化目录」
- 顶部蓝色按钮「重置强化点数」
- 4 列图标格，每格：名称 + 图标 + 层数格子（空格=未买）
  - 力量(5层) 防御(3) 生命上限(3) 恢复(5)
  - 冷却时间(2) 攻击范围(2) 飞射速度(2) 持续时间(2)
  - 发射数量(1) 移动速度(2) 念力(2) 运气(3)
  - 下一行：成长、贪欲、诅咒、复活机会 …（可滚动）
- 选中格底部详情：名称、图标、说明、价格（金币）、「购买」按钮
  - 例：力量——每强化一层，造成的伤害+5%，最多+25%（200金币）

## 可借鉴点（待讨论）
- 结算页的「每秒伤害」对比能让玩家看出哪把武器强，利于理解构筑。
- 局外成长走「金币买永久小加成」，层数少、价格递增；与我们的「转生特典」可并行。
- 成就解锁新道具/新武器，作为长期目标。
