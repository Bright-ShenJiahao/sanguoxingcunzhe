# 美术提示词（中文，发给出图 AI）

统一规则：细像素风；背景纯洋红 #FF00FF；无阴影、无文字；每帧画布大小一致；脚底位置一致；人物朝右。
不再画任何攻击动作：身体只有 待机 / 走路，武器作为独立图自己动。

## 1. 男主 · 单手握持（短武器用）——最先出
参考我发的男主细像素图，保持相同的像素精细度、身高比例、俯瞰略带侧面的视角。画一张动作表，一排8帧：前2帧待机（轻微呼吸起伏），后6帧走路（左右腿交替迈步，手臂前后摆动）。姿势：右手握拳放在身体右前方（腰高），像握着一件看不见的武器，不要画武器。每帧画布大小相同，脚底在同一水平线。

## 2. 男主 · 双手握长柄（长枪/长杆用）
同上，同样的角色和排布（2帧待机 + 6帧走路），姿势改为：双手一前一后握住一根看不见的长杆，斜放在身体前方，不要画杆。

## 3. 男主 · 举弓 / 持弩
同上，2帧待机 + 6帧走路。第一排：左臂向前伸直、右手收在胸前，像举着弓拉弦前的姿势；第二排：双手平端在胸前，像端着弩。不要画弓和弩。

## 4. 男主 · 空手摊开（法器悬浮用）
同上，2帧待机 + 6帧走路，右手掌心向上摊在身侧，不要画任何物品。

## 5. 女主（同样的 4 套姿势）
人物换成年轻女性：白色短袖，深蓝牛仔短裤，白色运动鞋，黑色高马尾，红色发带，腰间小布包。身高、画布大小、姿势、帧排布与男主完全一致，分别出“单手握持 / 双手握长柄 / 举弓持弩 / 空手摊开”四张表。

## 6. 武器（每件单独一张，竖直放置，握点在中下部）
参考我发的武器图，保持相同像素精细度，重绘以下武器，每件单独画在洋红底上，竖直放置，刃/头朝上，握柄在下三分之一处，并在握柄中心用一个红色单像素点标出握点：柳叶刀、直剑、长枪、方天画戟、青龙偃月刀、汉弓、弩、八卦铜镜。

## 7. 黄巾兵（只要走路，不要攻击）
黄头巾、土黄衣服的农民叛军，细像素，与男主同样的视角和精细度，身高略矮。一排8帧：2帧待机 + 6帧走路；再加1帧受击（身体后仰）和2帧倒地。姿势：双手握拳放在身前，不要画武器。做杂兵、枪兵、盾兵（盾牌画在左臂上）、弓手四种，每种一张表。
